Air Quality Trend Analysis – Ghatkopar, Mumbai

Project Overview

This project focuses on analyzing air quality trends in Ghatkopar, Mumbai, using environmental monitoring data collected from OpenAQ.

Objectives

- Study variations in air pollution levels.
- Analyze major air pollutants.
- Understand air quality trends through visualizations.

Dataset

- Source: OpenAQ
- Location: Ghatkopar, Mumbai
- Study Period: 20 September 2026 – 30 September 2026
- Parameters: PM2.5, PM10, NO₂ and O₃

Tools Used

- Python
- Microsoft Excel
- Data Visualization

Project Work

- Collected and reviewed environmental data.
- Examined pollutant measurements.
- Prepared trendline graphs to understand variations in pollution levels.

Key Learning

This project provided practical experience in working with environmental datasets, analyzing pollutant measurements and presenting trends through visualizations.
